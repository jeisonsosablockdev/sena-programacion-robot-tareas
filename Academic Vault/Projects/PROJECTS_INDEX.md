# Projects Index

This table is the canonical registry of projects in the vault.

Rules:

- Every real project must live in its own folder under `Projects/`.
- Every project folder must contain `PROJECT_INDEX.md`.
- Formal delivery work should also include `PROJECT_REQUIREMENTS.md` and `EXPORT_MANIFEST.md` when applicable.
- Canonical project writing lives in `Drafts/<Project Name>/`, `Reviews/<Project Name>/`, and `Hypotheses/<Project Name>/`.
- Project folders should expose `Drafts`, `Reviews`, and `Hypotheses` as symlink views to those canonical folders.
- `PROJECT_INDEX.md` and `EXPORT_MANIFEST.md` must point to the canonical paths, not to the symlink views.
- Do not create standalone project notes directly in `Projects/`.
- After creating or restructuring a project, rebuild this index.
