# Export Rules

- Keep `document_status: draft` until the user explicitly approves a final version.
- List draft files in the exact order they must appear in the final document.
- Keep bibliography paths current if citations are used in Pandoc format.
- Keep `pdf_watermark: true` unless the institution or the user explicitly requires a clean export without watermark.
- Point `drafts:` to canonical paths such as `Drafts/<Project Name>/...`, never to `Projects/<Project Name>/Drafts`.
