## Objetivos de Aprendizaje del Programa

1. **Análisis y Especificación de Requisitos:** Levantar requerimientos funcionales y no funcionales, casos de uso, historias de usuario y diagramas UML bajo estándares de la industria.
2. **Diseño de Arquitectura y Base de Datos:** Modelar bases de datos relacionales (diagramas ER, normalización SQL) y estructurar arquitecturas de software modulares y desacopladas (MVC, Layered).
3. **Desarrollo de Software Backend & Frontend:** Construir aplicaciones utilizando lenguajes tipados y orientados a objetos, implementando APIs RESTful, lógica de negocio y buenas prácticas (Clean Code, SOLID).
4. **Pruebas y Calidad de Software (QA):** Diseñar y ejecutar planes de pruebas unitarias, de integración y validación de software para asegurar robustez y trazabilidad.
5. **Control de Versiones y Despliegue:** Gestionar el ciclo de vida del código con Git/GitHub, control de ramas (GitFlow/Trunk), integración continua y documentación técnica estructurada.
6. **Ética, Comunicación y Trabajo Colaborativo:** Presentar informes técnicos, manuales de usuario, bitácoras de proyecto y sustentar proyectos formativos.

## Competencias Técnicas Clave

- **Algoritmia y Lógica Computacional:** Estructuras de control, modularidad, complejidad algorítmica y estructuras de datos fundamentales.
- **Programación Orientada a Objetos (POO):** Clases, objetos, herencia, polimorfismo, encapsulamiento, abstracción e interfaces.
- **Modelado de Sistemas (UML):** Diagramas de clases, casos de uso, secuencia, actividades y despliegue.
- **Persistencia de Datos:** SQL DDL/DML, normalización (1FN, 2FN, 3FN), consultas avanzadas, joins, procedimientos almacenados e indexación (MySQL / PostgreSQL).
- **Desarrollo Web & Servicios:** Protocolo HTTP/HTTPS, APIs REST, JSON, frontend básico (HTML5/CSS3/JavaScript) y frameworks backend.
- **Seguridad en el Software:** Validación de entradas, prevención de inyecciones SQL/XSS, autenticación, autorización y manejo seguro de variables de entorno.

## Tipología de Evidencias de Aprendizaje SENA

En el marco de formación por proyectos del SENA, los entregables se clasifican habitualmente en:

1. **Evidencias de Conocimiento (EC):**
   - Cuestionarios, mapas conceptuales, cuadros comparativos y análisis teóricos sobre conceptos de software y computación.
2. **Evidencias de Desempeño (ED):**
   - Demostraciones de codificación en vivo, participación en foros temáticos, sustentaciones técnicas, sesiones sincrónicas y ejecución de pruebas.
3. **Evidencias de Producto (EP):**
   - Código fuente en repositorios GitHub con commits semánticos y tests automatizados.
   - Documentos de análisis y especificación (SRS, IEEE 830).
   - Scripts DDL/DML de bases de datos pobladas.
   - Manuales técnicos (instalación, despliegue, arquitectura) y manuales de usuario final.
   - Informes técnicos en PDF generados a partir de Markdown con rigor académico.

## Criterios de Evaluación y Calidad SENA

- **Aprobado (A) / No Aprobado (D):** El sistema SENA es binario por competencia; para alcanzar la calificación de "A" se exige cumplimiento exhaustivo de la lista de chequeo de la evidencia.
- **Rigor Técnico:** Código limpio, sin variables mágicas, bien indentado, con nomenclatura estándar (camelCase, snake_case según lenguaje) y tests funcionales.
- **Puntualidad y Presentación:** Formato institucional correcto, ortografía técnica impecable, referencias bibliográficas en norma APA 7 y entrega en los tiempos estipulados en el cronograma formativo.
