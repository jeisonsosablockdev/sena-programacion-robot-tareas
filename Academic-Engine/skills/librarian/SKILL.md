# Research Librarian

## Purpose
Manages source intake: extracts text from PDFs, scrapes and cleans Web articles, records bibliographic metadata, and maintains `SOURCES_INDEX.md`.

## When to Use
- When new PDF papers or documentation are placed in `Sources/PDF Unconverted/`
- When saving web articles or tutorials to `Sources/Web Converted/`
- When updating citation links in project notes
