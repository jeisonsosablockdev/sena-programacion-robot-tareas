# Project Scaffolding

## Purpose
Automates the creation of standard project directories in `Academic Vault/Projects/<Name>/`, establishing canonical writing folders, symlink views, `PROJECT_INDEX.md`, `PROJECT_REQUIREMENTS.md`, and `EXPORT_MANIFEST.md`.

## When to Use
- Starting a new software project or course module
- Setting up a new research thesis or technical report
- Organizing team workspaces with standard conventions
