# Software Engineering

## Purpose
Guides system architecture, software requirements engineering, development lifecycles (agile, Scrum), design patterns, and deployment pipelines.

## When to Use
- Designing software architectures (Layered, Clean, MVC, Microservices)
- Drafting Software Requirements Specifications (SRS / IEEE 830)
- Defining CI/CD workflows and automated test strategies
- Modeling system components with UML diagrams
